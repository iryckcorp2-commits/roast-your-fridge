One line, at most 200 characters, roasting the most boring thing in the kitchen: My fridge is the loudest thing in my kitchen, humming all night like a tiny engine with big dreams and nothing inside but regret and one sad pickle.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 148 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
